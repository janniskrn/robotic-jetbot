# Decks ledger

One entry per deck actually given. Newest first. Append **after** the talk, not after
the build, because the useful half only exists once it has been spoken in a room.

One exception, and it is marked as such: when a deck is finished and handed in but not
yet spoken, write the build half straight away with every room field set to `open`.
Waiting loses the build half, and the build half is where the correction rounds live.
Fill the room fields in after the talk, in the same entry.

## Fields

| Field | Why it is here |
|---|---|
| `date` · `project` · `occasion` | Which deck this was |
| `sections` | Planned count, and how many were actually shown |
| `minutes` | Planned against spoken. The gap is the single most reusable number here |
| `look` | Direction name, cross-referenced to the `design-directions` ledger |
| `cut live` | Which sections were skipped while speaking, and why |
| `broke` | What failed in the room: projector, colour, font, timing, a question |
