itotal architecture of the code

Code architecture: three layers and the driving loop

3136 lines in 26 Python files, all written by us. The stock NVIDIA notebooks are untouched and used as building blocks only. Data flows one way, and the layers are separated by their imports, not by a comment.

Provable in one command: grep "^import|^from" perception.py decision.py control.py. Neither decision.py nor control.py imports jetbot, so neither can reach a motor.

1 · cameraFrame224 × 224 px, nominal 21.6 to 22.8 Hz
2 · perceptionThree modelsResNet18, TensorRT lane: visible, xcurve: class, sidecup: seen, row, x

The lane model runs on every frame. Curvature and obstacle models alternate across frames: evaluating all three concurrently introduced +12 ms control latency per step, inducing steering phase lag.

Measured in the Task 1 runs: 29.8 ms per step with three models, 21.6 to 22.8 steps per second. TensorRT took one lane pass from 41 ms to 10.6 ms.

ii + iiisource code · the state machine

State machine: seven states and the avoidance phases

phase 1 · active brake0.1 s reverse pulse followed by 0.3 s dwell. Eliminates rolling inertia before initiating rotation
phase 2 · outward pivotIn-place rotation until obstacle exits visual field laterally (nominal ~90 deg yaw change)
phase 3 · bypass arcTangential feed while obstacle is lateral, followed by differential arc until lane tape traverses robot underside
phase 4 · inward pivotCounter-rotation terminating when lane alignment is restored and lateral offset ≤ 0.4

All phases feature sensory termination criteria bounded by safety timeouts, compensating for the lack of wheel encoders and IMU. Transition specifications: notebooks/mini_av/STATE_MACHINE.md.

16def limit_change(target, current, up_rate, down_rate, dt):
17    """Moves current toward target by at most up_rate (rising) or down_rate (falling) per second"""

38    def target_speed(self, curve_probs, lane_x):
39        """Slower of two speeds: the curve model's (blended by its probabilities) and the steering's.
40
41        The steering part keeps the robot slow while it is still turning, also when the curve model
42        already sees the straight ahead.
43        """
44        model_speed = sum(p * v for p, v in zip(curve_probs, SPEEDS))
45        turning = (abs(lane_x) - config.TURN_SLOW_START) / (config.TURN_SLOW_FULL - config.TURN_SLOW_START)
46        turning = max(0.0, min(1.0, turning))
47        steering_speed = config.SPEED_STRAIGHT - turning * (config.SPEED_STRAIGHT - config.SPEED_SHARP)
48        return min(model_speed, steering_speed)

50    def curve_turn(self, curve_probs, curve_dir):
51        """Base turn for the curve the curve model sees: a curve needs a sustained turn that P alone only gives
52        with a large error. Size from how sharp the curve is, direction from which way it bends (both curve model)"""
53        if abs(curve_dir) < config.FEEDFORWARD_MIN_DIR:
54            return 0.0
55        size = curve_probs[1] * config.FEEDFORWARD_GENTLE + curve_probs[2] * config.FEEDFORWARD_SHARP
56        return size if curve_dir > 0 else -size

58    def feedforward(self, curve_probs, curve_dir):
59        """The curve turn, or none when the robot is already inside the curve: then P steers it back to the center"""
60        if self.lane_x * curve_dir < 0 and abs(self.lane_x) > config.FEEDFORWARD_MAX_INSIDE:
61            return 0.0
62        return self.curve_turn(curve_probs, curve_dir)

64    def update(self, lane_x, curve_probs, curve_dir, dt, speed_limit=None):
65        """Returns (left, right) wheel speeds; speed_limit caps the target speed (state SLOW_DOWN)"""
66        if self.baseline:
67            # stock JetBot style: raw model output, plain P steering, constant speed
68            self.steering = config.STEERING_KP * lane_x
69            self.speed = config.BASELINE_SPEED
70        else:
71            self.lane_x += config.LANE_SMOOTHING * (lane_x - self.lane_x)
72            if self.last_error is None:
73                self.d_lane_x = self.lane_x
74            self.d_lane_x += config.D_SMOOTHING * (self.lane_x - self.d_lane_x)
75            change = 0.0 if self.last_error is None else (self.d_lane_x - self.last_error) / dt
76            self.last_error = self.d_lane_x
77            # leaky integral: grows while the robot stays off-center in a curve, fades on the straight
78            self.integral += self.lane_x * dt - self.integral * dt / config.STEERING_I_LEAK
79            integral_part = max(-config.STEERING_I_MAX, min(config.STEERING_I_MAX, config.STEERING_KI * self.integral))
80            # gain scheduling: the faster the robot, the more a correction moves it before the next frame,
81            # so the gains shrink with speed and the steering has the same effect at every speed
82            schedule = config.STEERING_REF_SPEED / max(self.speed, config.STEERING_REF_SPEED)
83            wanted = (schedule * (config.STEERING_KP * self.lane_x + config.STEERING_KD * change) + integral_part
84                      + self.feedforward(curve_probs, curve_dir))
85            self.steering = limit_change(wanted, self.steering, config.STEERING_RATE, config.STEERING_RATE, dt)
86            if self.use_curve:
87                target = self.target_speed(curve_probs, self.lane_x)
88                if speed_limit is not None:
89                    target = min(target, speed_limit)
90                self.speed = limit_change(target, self.speed, config.SPEED_UP_RATE, config.SPEED_DOWN_RATE, dt)
91            else:
92                self.speed = config.BASELINE_SPEED  # same speed as the baseline: the runs differ only in steering
93        return self.wheels()

95    def hold(self, curve_probs, curve_dir, dt):
96        """Returns (left, right) for a short gap in which the lane is not visible (lane_x is not trained on
97        such frames). In a curve the robot keeps turning into it, at least as hard as the curve turn: holding

106    def avoid(self, phase, side, elapsed):
107        """Returns (left, right) for a swerve phase (decision.AVOID_PHASES; the decision layer picks and ends it).
108
109        brake: stand still; turn_out, turn_in: turn in place toward the pass side; arc: curve away from it, around
110        the cup; pass: straight on while the cup is in view during the curve (Decision.avoid_action).
111        side: 'left' or 'right', the pass side; elapsed: seconds since the phase started (the kick).

113        if phase == 'brake':
114            return self.stop(phase, elapsed)
115        if phase == 'pass':

118        if phase == 'arc':
119            outer, inner = config.ARC_WHEELS

126        because at 0 the motor board lets the wheels coast; back = slowly backwards; wait = off"""
127        if phase == 'back':
128            return -config.BACKUP_SPEED, -config.BACKUP_SPEED
129        if phase == 'brake' and elapsed < config.BRAKE[1]:

137        self.steering = (config.RECOVER_TURN if side == 'left' else -config.RECOVER_TURN)
