itotal architecture of the code

Code architecture: three layers and the driving loop

3136 lines in 26 Python files, all written by us. The stock NVIDIA notebooks are untouched and used as building blocks only. Data flows one way, and the layers are separated by their imports, not by a comment.

Provable in one command: grep "^import|^from" perception.py decision.py control.py. Neither decision.py nor control.py imports jetbot, so neither can reach a motor.

itotal architecture of the code

Inference and control loop (per-frame)

1 · cameraFrame224 by 224 pixels, about 21 per second
2 · perceptionThree modelsResNet18, TensorRT lane: visible, xcurve: class, sidecup: seen, row, x
3 · decisionState machineSix states, first matching branch wins
4 · controlSteering and speedPD with gains scaled by speed, curve feedforward
5 · motorsWheelsBehind a battery guard, a camera watchdog and a motor watchdog

The lane model runs on every frame. The curve model and the cup model take turns on alternate frames, because all three on every frame cost 12 ms more per step and the steering got worse.

Measured in the Task 1 runs: 29.8 ms per step with three models, 21.6 to 22.8 steps per second. TensorRT took one lane pass from 41 ms to 10.6 ms.

ii + iiisource code · the state machine

State machine: seven states and the avoidance phases

phase 1 · brakeA reverse pulse, then stand still 0.3 s. Turning while rolling carried the robot into the lane edge
phase 2 · turn outTurn in place until the cup has left the image sideways, about 90 degrees
phase 3 · arcStraight on while the cup is beside, then 0.36 and 0.31 until the lane is crossed
phase 4 · turn inTurn back until the lane is aligned and within 0.4 of the middle

Every phase ends on a camera mark and has a time limit; the robot has no encoders and no gyro. The table with entry condition, action, exit condition and priority for all seven states is notebooks/mini_av/STATE_MACHINE.md.

38    def target_speed(self, curve_probs, lane_x):
39        """Slower of two speeds: the curve model's (blended by its probabilities) and the steering's.
40
41        The steering part keeps the robot slow while it is still turning, also when the curve model

44        model_speed = sum(p * v for p, v in zip(curve_probs, SPEEDS))
45        turning = (abs(lane_x) - config.TURN_SLOW_START) / (config.TURN_SLOW_FULL - config.TURN_SLOW_START)

50    def curve_turn(self, curve_probs, curve_dir):
51        """Base turn for the curve the curve model sees: a curve needs a sustained turn that P alone only gives
52        with a large error. Size from how sharp the curve is, direction from which way it bends (both curve model)"""
53        if abs(curve_dir) < config.FEEDFORWARD_MIN_DIR:
54            return 0.0

60        if self.lane_x * curve_dir < 0 and abs(self.lane_x) > config.FEEDFORWARD_MAX_INSIDE:

64    def update(self, lane_x, curve_probs, curve_dir, dt, speed_limit=None):
65        """Returns (left, right) wheel speeds; speed_limit caps the target speed (state SLOW_DOWN)"""
66        if self.baseline:
67            # stock JetBot style: raw model output, plain P steering, constant speed
68            self.steering = config.STEERING_KP * lane_x
69            self.speed = config.BASELINE_SPEED
70        else:
71            self.lane_x += config.LANE_SMOOTHING * (lane_x - self.lane_x)
72            if self.last_error is None:

74            self.d_lane_x += config.D_SMOOTHING * (self.lane_x - self.d_lane_x)
75            change = 0.0 if self.last_error is None else (self.d_lane_x - self.last_error) / dt
76            self.last_error = self.d_lane_x
77            # leaky integral: grows while the robot stays off-center in a curve, fades on the straight
78            self.integral += self.lane_x * dt - self.integral * dt / config.STEERING_I_LEAK
79            integral_part = max(-config.STEERING_I_MAX, min(config.STEERING_I_MAX, config.STEERING_KI * self.integral))
80            # gain scheduling: the faster the robot, the more a correction moves it before the next frame,
81            # so the gains shrink with speed and the steering has the same effect at every speed
82            schedule = config.STEERING_REF_SPEED / max(self.speed, config.STEERING_REF_SPEED)
83            wanted = (schedule * (config.STEERING_KP * self.lane_x + config.STEERING_KD * change) + integral_part
84                      + self.feedforward(curve_probs, curve_dir))
85            self.steering = limit_change(wanted, self.steering, config.STEERING_RATE, config.STEERING_RATE, dt)
86            if self.use_curve:

88                if speed_limit is not None:
